# Vehicle Configurator

A B2B Vehicle Configuration Portal built using both **Spring Boot (Java)** and **ASP.NET Core (.NET 8)** architectures.

The system allows leasing companies to configure vehicles based on predefined conditions, dynamically calculate pricing, and generate invoices in PDF format.

---

## 📌 Project Overview

This project demonstrates a complete full-stack implementation in two different backend technologies:

- Java (Spring Boot Microservice Architecture)
- .NET Core (Web API Architecture)
- React JS Frontend

The application enables:

- User Registration & Login (JWT + OAuth)
- Vehicle Selection by Segment & Manufacturer
- Dynamic Component Configuration
- Default Configuration Management
- Real-time Price Calculation
- Invoice Generation (PDF)
- Email Notifications
